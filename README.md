# DJ VOKA Entertainment

Official website for DJ VOKA, also known as DJ Real Voka, based in Benin City, Edo State, Nigeria.

## Files

- `index.html` - Homepage and SEO metadata
- `style.css` - Responsive styling
- `script.js` - Navigation and page behavior
- `images/` - DJ VOKA photos and logo
- `robots.txt` - Search crawler instructions
- `sitemap.xml` - Canonical website sitemap

## Deployment

This is a static website and can be deployed directly from the repository with GitHub Pages or Vercel.

Canonical website: https://djvoka.name.ng/
